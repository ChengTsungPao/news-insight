# React Native Sample App

## 🚀 Getting Started

### 1. Install Dependencies

Open your terminal, navigate to this project folder, and run:

```bash
npm install
```

### 2. Run the App

Quickly run and test your app directly in your web browser:

```bash
npm run web
```

---

## 🛠️ Modifying the App

Open `App.js` in your code editor. Any changes you make will automatically reload in your browser.
