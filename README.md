# News Insight 

This is the central repository for **News Insight**, a modern news reading application.
This project is separated into a frontend mobile application and a backend API service.

## Project Structure

- **[`/frontend`](./frontend/)**: Contains the Flutter mobile application source code (iOS & Android). See the [Frontend README](./frontend/README.md) for setup and run instructions.
- **[`/backend`](./backend/)**: Contains the backend API services and database logic. See the [Backend README](./backend/README.md) for setup and run instructions.

## Getting Started

To get started with development, you can clone this repository and refer to the respective subdirectories for platform-specific instructions.

```bash
git clone <repository-url>
cd news_insight
```

After cloning, choose which part of the application you'd like to work on and navigate into its directory.

- For frontend development:
  ```bash
  cd frontend
  ```

- For backend development:
  ```bash
  cd backend
  ```
